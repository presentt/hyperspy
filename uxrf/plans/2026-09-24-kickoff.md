### Facts the plan rests on (verified this session)

  in `.github/copilot-instructions.md` and `.github/instructions/*.md`, AI policy in
  `doc/dev_guide/coding_with_ai.rst`. `CLAUDE.md` must be a thin layer pointing there.
- Ecosystem split (from `hyperspy/io.py`, `hyperspy/extensions.py`, `doc/user_guide/io.rst`):
  file readers live in **RosettaSciIO** (`rsciio.bruker` reads `.bcf`); `EDS_SEM`,
  `EDS_TEM`, X-ray line database, `add_elements`, `get_lines_intensity`, quantification
  live in **eXSpy**; GUIs are `hyperspy_gui_ipywidgets`, `hyperspy_gui_traitsui`, and
  the Qt app **HyperSpyUI**. Core HyperSpy has no EDS/XRF code. Extensions register via

  accepted proposal is required before non-trivial AI-assisted implementation PRs are
  reviewed in hyperspy / rosettasciio / etc.

  `hv > 30 → EDS_TEM else EDS_SEM`. A 50 kV M4 Tornado map loads as `EDS_TEM` unless
  `hs.load(f, instrument="SEM")`. rsciio docs: M4 Tornado / M6 Jetstream support is
  "poorly documented and tested". Useful kwargs: `downsample`, `cutoff_at_kV`,
  `select_type`, `lazy=True`.
- `.bcf` metadata needs no redaction (user decision: institutional instrument PC,
  generic operator name; proprietary data simply will not be shared).
- Environment: `import hyperspy` works only from the checkout (no dist metadata);
  `rsciio`, `exspy` not installed; `ruff`, `pytest` present. Git identity in the
  container is `Claude <noreply@anthropic.com>`. `data.caltech.edu` and `doi.org` are
  denied by the environment network policy (proxy 403), so the CaltechDATA `.bcf`
  files (30 MB and 100 MB, record `nea2t-91s77`) cannot be fetched here until the user
  allows the host or uploads a file. The MATLAB scripts the user mentioned did not
  arrive in the session.
- Commit trailer: pre-commit `commit-msg` hook `scripts/check-ai-co-author.py` rejects
  `Co-authored-by:` naming an AI tool; required form `Assisted-by: <tool>:<model>`.
  This overrides the harness's default `Co-Authored-By` footer.
- pytest always runs with xdist (`addopts = "-n auto --dist loadfile"`); a single test
  needs `-p no:xdist`. Doctests: `pytest --doctest-modules --ignore=hyperspy/tests`.

## MATLAB workflow → HyperSpy mapping (from the uploaded scripts)

Uploaded: `import_uxrf.m`, `uxrf_montage.m`, `Ileret_RtP4_figs.m`, and the Live Scripts
`plot_maps.mlx`, `tricolor_plots.mlx` (which also embed `img_proc_uxrf`,
`uxrf_labeled_montage`). Copies go in `uxrf/matlab_reference/` unchanged.

Pipeline today: Esprit exports one ASCII `.txt` matrix of counts per element
(`<prefix>_<Element>.txt`); pixel size is typed in by hand; per element the script keeps
raw, min–max normalised, Gaussian-blurred, and blurred+normalised maps plus a spatial
reference; figures are single maps with colour bar, count histograms, labelled montages
with per-element gamma (optionally histogram-equalised), RGB tricolour composites with
percentile stretch and a scale bar saved to TIFF, log10 ratio maps (S/Fe, Ca/P), and
pixel-wise 2D histograms against Ca.

| MATLAB step | HyperSpy equivalent (verified in this checkout) |
|---|---|
| `importdata(txt)` + `imref2d(px)` | `np.loadtxt` → `hs.signals.Signal2D`, set `axes_manager.signal_axes` scale/units (recipe 02); or skip Esprit entirely: `.bcf` → eXSpy `get_lines_intensity()` maps |
| `imgaussfilt(counts, sd)` | `s.map(scipy.ndimage.gaussian_filter, sigma=sd)` (documented example in `BaseSignal.map`) |
| min–max `norm` / `blur` | signal arithmetic: `(s - s.min()) / (s.max() - s.min())` |
| `uxrf_montage` (grid, labels, gamma, histeq) | `hs.plot.plot_images(maps, per_row=, label=, scalebar='all', axes_decor='off', vmin='1th', vmax='99th', norm=...)`; gamma via matplotlib `PowerNorm` passed as `norm` |
| `histogram(cps)` | `s.get_histogram().plot()` / `hs.plot.plot_histograms` |
| `cat(3, r, g, b)` + `stretchlim` + `imwrite(tif)` | stack three stretched maps as `Signal1D` with 3-channel signal axis, `change_dtype("rgb8")`, plot / `plot_images`; save with `s.save("x.tif")` (RosettaSciIO TIFF writer, needs `tifffile`) |
| `log10(A./B)` ratio maps | `(a / b).map(np.log10)` or `np.log10(a / b)` |
| `histogram2(Ca, X)` cross plots | not in HyperSpy core: matplotlib `hist2d` on `.data.ravel()` (small helper in the recipe) |
| scale bar, labels | `plot_images(scalebar=...)`, `label=` |
| gamma/histeq per element | matplotlib `PowerNorm`; equalisation via `skimage.exposure` if wanted (scikit-image is already an optional dependency) |

Recipes to write (small, one purpose each; only 01 and 02 in this session, the rest are
logged as backlog in `uxrf/NOTES.md` so the user can review a little at a time):
- `01_load_bcf_inspect.py`: load `.bcf`, report signal type/axes/metadata, sum spectrum,
  element maps from the raw spectrum image.
- `02_esprit_ascii_to_signals.py`: reproduce `import_uxrf` — glob the `.txt` exports,
  build calibrated `Signal2D` maps keyed by element, optional Gaussian blur and
  normalisation, `plot_images` montage. This gives the user parity with the MATLAB
  workflow on day one and is testable without a `.bcf` (a tiny synthetic ASCII export is
  generated in the recipe's `--demo` mode, all-different dims).
- Backlog: `03_rgb_composite.py` (tricolour + TIFF), `04_ratio_and_crossplots.py`,
  `05_bcf_vs_esprit_maps.py` (compare raw-spectrum-derived maps against Esprit exports;
  this is where Esprit's processing and Bruker metadata quirks get quantified).
